FOX01 제외 (FOX02 ~ FOX99)

실시간 동기화 (Firebase)

Firebase Database URL과 접속코드(PIN)를 입력하면 여러 기기에서 실시간 동시 편집됩니다.

※ 기본 서버와 접속코드가 자동 설정되어 프로필 선택 시 바로 연결됩니다. 공유 링크를 복사하면 현재 프로필(?profile=) 주소가 복사됩니다.

프로필 선택

사용할 공연/버전 프로필을 선택하면 해당 실시간 기록판으로 바로 연결됩니다.
